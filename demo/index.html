Tuppence

Each button does some component work. The library draws that work as bars in the Chrome DevTools Performance panel, laid out like React's own performance tracks.

  1. Open DevTools and go to the Performance panel.
  2. Press record, click a few buttons below, then stop.
  3. Open the Web Components · Tuppence group. Scheduler shows each update's steps, Components shows which element did the work, and Upgrade shows customElements.define. Click a bar to see its details.

Add ?strategy=timestamp to the address for the lightest mode, where bars have no details.
