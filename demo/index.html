custom-element-perf-tracks

Each button does some component work. The library draws that work as bars in the Chrome DevTools Performance panel.

  1. Open DevTools and go to the Performance panel.
  2. Press record, click a few buttons below, then stop.
  3. Look for a group called Web Components with Lifecycle, Upgrade and Updates tracks.

Plain custom element

Feeds the Upgrade and Lifecycle tracks, via definePerf

Lit element

Feeds the Updates track, via trackLitUpdates

Stencil (simulated)

Feeds the Updates track, via observeStencilProfile
